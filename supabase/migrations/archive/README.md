# Archived migrations (001–105)

These are the historical migrations, moved here so the top-level
`supabase/migrations/` folder shows only the newest few — no scrolling past 100
files to find the next one to run.

They are **kept for the record only**; all of them have already been applied.
New migrations continue to be numbered sequentially and live at the top level
(`supabase/migrations/1NN_*.sql`); move them here once they're comfortably live.

Nothing reads this directory programmatically — migrations are pasted into the
Supabase SQL editor by hand — so relocating them is purely organizational.
